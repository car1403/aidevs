# Optional LangChain Assignment

여행 일정 Chain과 같은 구조로 교육 과정 추천 Chain을 만드세요.

```text
학습자 입력 정리
→ 과정 추천
→ 추천 결과 Schema 검증
→ 주의사항 추가
```

순수 Python 함수만 사용한 버전과 LangChain 버전의 차이도 작성합니다.

## 제출 조건

- Pydantic 입력 및 결과 Schema
- `@tool`로 정의한 읽기 전용 Tool 두 개 이상
- 검색 근거와 source ID를 반환하는 RAG 단계
- session별 대화 기록 분리
- 정보 조회는 자동 실행하고 변경 작업은 승인 단계로 보내는 분기
- 정상, 입력 오류, 검색 결과 없음 시나리오 테스트

## 선택 확장

동일한 기능을 `create_agent`와 직접 구성한 `StateGraph`로 각각 구현하고 다음을
비교합니다.

1. 코드에서 실행 순서가 얼마나 명확하게 보이는가?
2. Tool 반복 호출을 어디에서 제한하는가?
3. 승인 전후 상태를 어떻게 저장하는가?
4. 특정 단계만 단위 테스트하기 쉬운 구조는 어느 쪽인가?
