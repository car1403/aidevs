# Multi-Agent 학습 지도

```text
역할 분리
→ 계약
→ Router
→ Workflow
→ Orchestration
→ LangGraph
→ Handoff
→ 검증·승인
→ 실패 통제
→ 비동기 서비스
→ 관측·운영
```

새 용어를 다음 일상 표현과 연결합니다.

| 기술 용어 | 일상 표현 |
| --- | --- |
| Supervisor | 총괄 담당자 |
| Worker | 업무 담당자 |
| Router | 안내 데스크 |
| Handoff | 업무 인계서 |
| State | 공동 작업 기록 |
| Trace | 처리 과정 |
| Fallback | 대체 처리 |
| Escalation | 사람에게 전달 |
